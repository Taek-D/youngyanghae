# 영양해 — 수동 E2E 테스트 플랜

> **대상**: 런칭 전 실기기 토스앱 2대 이상 (샌드박스 UserAgent는 IAP 테스트 불가)
> **실행**: 심사 제출 직전 필수

## 🎯 핵심 시나리오 (10개)

### S1. 최초 설치 플로우
- [ ] 앱 첫 실행 → **인트로 화면** 표시 (홈 바로 진입 X)
- [ ] 뒤로가기 탭 → **미니앱 종료** (리프레시 X)
- [ ] "영양해 시작하기" 탭 → 홈 이동
- [ ] 재실행 시 → 인트로 스킵, 홈 바로 진입

### S2. 영양제 등록 기본
- [ ] 홈 Empty state "영양제 추가하기" → `/supplements/new`
- [ ] 검색창에 "오메가3" 입력 → 자동완성 표시
- [ ] 검색 결과 탭 → 이름/용량/성분 자동 입력
- [ ] 슬롯 2개 선택 (아침·저녁)
- [ ] 요일 평일만 선택 (월~금)
- [ ] 저장 → 리스트 페이지에서 확인
- [ ] 홈 → 슬롯별 그룹화된 리스트 표시 (해당 요일만)

### S3. 1-tap 복용 체크 (핵심 UX)
- [ ] 홈 리스트 영양제 행 전체 탭 (버튼이 아닌 카드)
- [ ] 체크박스 애니메이션 200ms 내 완료
- [ ] 재탭 → 토글 (taken ↔ skipped)
- [ ] 탭 후 3초 내 상태 저장 확인 (앱 재시작 후 유지)

### S4. 스트릭 + 포인트 적립
- [ ] 3일 연속 체크 → +100p 적립 (스트릭 카드 3일 표시)
- [ ] 7일 연속 → +200p
- [ ] 하루 빼먹고 다음날 체크 → **스트릭 1로 리셋**, 최장 일수는 유지
- [ ] 같은 날 중복 체크 → 스트릭 변동 없음 (idempotent)

### S5. 프리미엄 게이팅 (4중)
- [ ] 무료 + 3개 등록 → 4번째 FAB 탭 → **페이월로 자동 리다이렉트**
- [ ] 히스토리 "월" 탭 → 페이월 이동
- [ ] 홈 완료 후 광고 버튼 → 시청 → +50p (프리미엄은 이 버튼 숨김)
- [ ] 8일 이전 기록 → 페이월 CTA 노출

### S6. IAP 결제 성공
- [ ] 페이월 → 월 구독 선택 → CTA 탭
- [ ] 토스 결제 창 노출 → 승인
- [ ] 성공 알림 → 홈 이동
- [ ] 설정 → 멤버십 "PRO" 배지 + 다음 결제일 표시
- [ ] 영양제 4개 이상 등록 가능 확인

### S7. IAP 결제 실패·취소
- [ ] 페이월 → CTA → 결제창 "취소"
- [ ] 앱 복귀 → 조용히 돌아옴 (에러 메시지 X)
- [ ] 네트워크 OFF 후 결제 시도 → 네트워크 에러 메시지 노출

### S8. 구매 복원
- [ ] 프리미엄 상태에서 앱 삭제 → 재설치
- [ ] 앱 시작 시 자동 restore() 호출 (백그라운드)
- [ ] 또는 설정 → 구매 복원 탭 → 프리미엄 복원 확인

### S9. 포인트 교환
- [ ] 1000p 이상 보유 상태
- [ ] 페이월 → "포인트로 교환하기" 탭
- [ ] 이중 confirm → 교환 → 프로 1일권 활성화
- [ ] 24시간 후 자동 downgrade (만료 → 무료)

### S10. 알림 + 데이터 초기화
- [ ] 설정 → 알림 ON + 아침 시간 09:30 변경
- [ ] 09:30 실기기 로컬 알림 수신 확인
- [ ] 설정 → 알림 OFF → 알림 수신 안됨
- [ ] 설정 → 모든 데이터 초기화 → 이중 confirm → 전체 삭제 → 인트로로 복귀
